**It's open source now.** 🎉

A few days ago I asked if I should open-source my LinkedIn MCP server. Here it is, MIT licensed:
👉 github.com/ivikasavnish/linkedin-mcp

**What you get:**
▸ Post to LinkedIn from Claude Code or any MCP client
▸ **Bold** and *italic* text, which LinkedIn's editor can't do
▸ Safe escaping, so brackets and @ signs don't cut your post short
▸ Real hashtags, images, link cards, drafts, company pages
▸ The 3 security fixes from my last post, already in

**Setup is about 5 minutes:**
1. Create a LinkedIn developer app
2. go build, then run the auth command
3. Add it to Claude Code

One Go binary. Runs on your machine. Your token stays there.

This post was published through it, link card and all.

Stars, issues and PRs welcome. What should it do next? 👇
